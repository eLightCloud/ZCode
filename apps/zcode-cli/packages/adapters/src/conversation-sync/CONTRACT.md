# 原生会话同步适配

唯一公开入口为现有 `@zcode/adapters/conversation-sync`。原生 contracts 拥有
正文 / 版本 / 请求的严格 schema；本模块实现原生 PG 事务、隔离 outbox、
固定对象字节和 continuation 编排，不接收浏览器自报的停止或恢复证明。

- PG writer 拥有候选、选择和原意图；Core / Host 拥有接纳屏障和恢复。
  outbox 的真实回执与接续锚点不同，不能用锚点伪造 ACK。
- 同一操作的完整指纹固定；未知结果重查原操作，不能换候选、模型或输入。
  断线不是停止证明，离线分支不提升当前主头，历史工具不重放。
- 本机持钥身份由 outbox writer 在原事务中登记；尚有未确认上传禁止换绑。
  旧存储委托可续发以补原上传，不因此获得控制权。私钥不进入公开合同。
- 工厂沿 index 复用现有 facade，管理策略、数据角色及资格保持分离。
  跨主体、未知格式和能力缺失均拒绝；不引入第二队列或企业执行 writer。
- 全部有效身份默认可同步本人合资格会话；配置只保留容量限额，不含账号开关或白名单。
  schema 6 增量移除旧准入字段并推进配置修订，不修改会话、正文与回执；重复迁移不重复推进。

私有 HTTP、Host 出站控制及字节存储仅是适配。Desktop continuous 与 Web
replayable 的接纳仍由同一 Core 实现；schema / RLS、取消与未知 ACK、真实
打包恢复、离线分支及独立迁移分别由对应回归证明。

生产扫描仅使用 Host source；直接 store source 仅保留在 checks 夹具。永久版本拒绝按会话隔离因果后继，scope / transport 中止本轮；错误码保持低敏可诊断。

首次登记通过同一 HTTP 分发调用 enroll；保存回执不代替在线接纳。普通删除
在会话行锁内拒绝未完成接续和未收口的已知离线 owner，原操作回执优先返回；
删除不要求正文恢复，不供给执行实例。journal 的终态提交同样持有会话锁。

固定文件在主体配额事务内先判累计占用，再经有界对象端口上传、回读和提交
准确回执；同主体并发文件与正文共享该锁。资源 owner 对未确认上传的重试
核验同一派生键的准确版本字节后复用；已确认读取始终使用原绑定及版本。

管理投影沿 configuration proof 与 policy facade 的 /monitoring，只暴露有界低敏
计数 / 时间和固定容量聚合。schema 7 保留全部会话及 policy 修订；configurator
仍不能读取正文表，只有固定聚合函数执行权。观察计数含重试、无终端离线积压，
其失败不能回滚已提交业务；数据缺失与当前进程观察失败必须显式表达。

终端队列观察复用同一 outbox / worker：先本地捕获，再由原 worker 补准确文件与
提交原操作。SQLite schema 7 只追加尝试、ACK 及报告游标；旧创建时间不伪造。
中心 schema 8 只存严格低敏来源报告，来源由可信 ingress 重建。报告是终端观察，
不是中心保存或停止证明；过期 / 未覆盖必须明确。本地 CAS 和单调序号保护并发、
账号切换及重启的报告顺序，观察失败不改变原操作或执行接纳。

本机扫描读取正文前复用 outbox 原归属核对；已知其它账号的会话不属于当前
扫描范围，不能误报为未知归属或触发认领。首个原命令解析后再次核对。未知
存量仍需原有明确确认，跨账号切换不改变任何既有 owner / 原请求。

管理 /usage 使用配置 proof，仅投影按 tenant 或 subject 的正文及文件占用，支持准确 tenant / subject、排除 tenant、稳定分页及完整匹配汇总。subject 筛选必须带 tenant。schema 9 只增加固定 SECURITY DEFINER 聚合函数，observer 仍只有元数据列读取权；不读取正文，不改变同步写入或 policy 修订。企业归属与用户名称由外部身份 owner 映射，不进入原生。
